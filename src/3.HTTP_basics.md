1. What is HTTP?

HTTP (HyperText Transfer Protocol) is a communication protocol used for transferring data between a client (browser/app) and a server on the web.
It defines how requests and responses are sent.

2. How HTTP Works (Simple Flow)

   Client (Browser/App) ----> sends HTTP Request ----> Server
   Server ----> sends HTTP Response ----> Client

3. HTTP Request

A request is what the client sends to ask for something.
A typical HTTP request contains:

- Method

GET → fetch data
POST → send data
PUT → update data
DELETE → remove data

- URL
The address of the resource (example: /products/123)

- Headers
Extra info like:

Content-Type
Authorization
Cookies
User-Agent

- Body (optional)
Sent mainly with POST/PUT (example: JSON data)

4. HTTP Response

- Server replies with:
Status Code
200 → OK
404 → Not Found
500 → Server Error
401 → Unauthorized

- Headers
Like: Content-Type, Set-Cookie, Cache-Control

- Body
Actual data returned (HTML, JSON, images, files)

5. HTTP is Stateless

Each request is treated independently.
The server does not remember previous requests unless:

cookies
tokens
sessions are used.
