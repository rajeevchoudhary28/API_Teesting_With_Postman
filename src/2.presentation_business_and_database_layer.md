1. Presentation Layer (UI Layer)

This is what the user sees and interacts with.
Examples: Website UI, mobile app screens, forms, buttons.
Its job: Take input from the user and show output.

Think of it as:
🎨 The front-end or user interface.

2. Business Layer (Logic Layer)

This layer contains the rules, calculations, and processing logic.
It decides how things should work.
It does not deal with UI or database directly.

Examples:
Validating login credentials
Calculating discounts
Checking inventory
Processing orders

Think of it as:
🧠 The brain of the application.

3. Database Layer (Data Layer)

This is where data is stored and retrieved.
Includes databases like MySQL, MongoDB, Oracle, SQL Server.
The business layer sends queries here.

Think of it as:
📦 The storage system.

How they work together (Simple Flow)
User (UI)
↓
Presentation Layer (App/Website)
↓
Business Layer (Logic/Rules)
↓
Database Layer (Data Stored)
↑
Business Layer (Process Result)
↑
Presentation Layer (Show Output)
